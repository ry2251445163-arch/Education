# 一、德育内涵
## ① 概念
1. 广义——所有有目的、有计划地对社会成员在政治、思想与道德等方面施加影响的活动（社会德育、社区德育、学校德育、家庭德育）
2. 狭义——学校德育
## ② 德育的意义
德育是实现我国教育目的的基础和保障
# 二、[[德育功能]]
## ① 社会性功能
## ② 个体性功能
## ③ 教育性功能
1. 德育的“教育”或价值属性
2. 德育作为~={red}教育子系统=~对~={red}平行系统=~的作用
# 三、[[德育目标]]
## ① 概念
德育目标是德育工作的出发点，不仅决定德育的内容、形式和方法，而且制约着德育工作的基本过程
## ② 确立德育目标的依据
1. 德育目标——决定内容
2. 受教育者的身心发展特征——决定深度和广度
3. 面对的时代特征和学生思想实际——决定针对性和有效性
4. 文化传统
# 四、[[德育内容]]
## ① 概念
德育目标确定了培养人的总体规格和要求，但必须落实到~={red}德育内容=~上
## ② 选择依据
1. 德育目标——决定内容
2. 受教育者的身心发展特征——决定深度和广度
3. 面对的时代特征和学生思想实际——决定针对性和有效性
4. 文化传统
# 五、我国学校德育内容
我国学校德育内容主要有政治教育、思想教育、道德教育和心理健康教育
1. 思想教育——人生观、世界观以及相应思想观念方面教育
2. 心理健康教育——学习辅导、生活辅导和择业指导
# 六、[[德育内容特点]]
1. 生活化
2. 综合化——品德教育、科学教育、社会文化教育
3. 生本性——生活实际出发，尊重学生已有的生活经验
4. 开放性
