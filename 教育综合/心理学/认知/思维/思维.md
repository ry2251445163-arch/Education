思维是人脑对~={red}客观事物=~的本质属性与内在联系的~={red}概括的、间接的=~反映
# （1）特征
## ① 间接性
思维能对~={red}感官所不能直接把握=~的或不在眼前的事物，借助于某些媒介物与头脑加工
例子：
1. 医生望闻问切
## ② 概括性
1. 把同一类事物的共同特征和本质特征抽取加以概括——统称为“果树”“水果”
2. 将多次感知道德事物之间的联系和关系加以概括，得出有关事物之间的内在联系——“月晕而风”“蜻蜓低飞蛇过道”
# （2）品质
1. 敏捷性
2. 灵活性
3. 深刻性
4. 批判性
5. 独创性
# （3）类型
1. 直观动作思维
2. 具体形象思维——利用头脑中的具体形象来解决问题
3. 抽象逻辑思维
4. 直觉思维——未经初步分析就迅速对问题答案做出合理的猜测
5. 分析思维
6. 聚合思维
7. 发散思维——一题多解
8. 常规性思维
9. 创造性思维——提出新的方案或程序，并创造出新的成果
# （4）基本形式
1. 概念
2. 判断
3. 推理
# （5）过程
1. 分析与综合——~={red}基本过程=~
2. 比较与分类——确认它们之间的异同点
3. 抽象与概括
