# （1）实质
1. ~={red}图式=~——形成自己独特的活动结构和组织
2. 同化——利用原来图式接受或解释新刺激
3. 顺应——不能利用图式接受或解释新刺激
4. 平衡
# （2）影响个体发展的因素
1. 成熟
2. 练习与经验
3. 社会经验
4. 平衡化
# （3）认知发展阶段
## ① [[感知运动阶段]]（0-2岁）
1. 客体永恒性——客体从眼中消失时，并非不存在
2. 儿童认知发展过程中的“哥白尼式的革命”
## ② [[前运算阶段]]（2-7岁）
1. ~={red}泛灵论（万物有灵论）=~
2. 具有自我中心性
3. 不可逆性
4. 刻板性
5. 不具有守恒性
6. 感知局限性
## ③ [[具体运算阶段]]（7-11岁）
1. 形成了守恒概念——长度、体积、重量和面积守恒的概念
2. 具有可逆性——大杯进小杯，并能小杯进大杯
3. 具有去自我中心性
4. 能进行具体的逻辑推理
5. 理解原则和规则
6. 具有多维思维
## ④ [[形式运算阶段]]（11岁以后）
钟摆实验
1. 能认识命题之间的关系
2. 能进行假设-演绎推理
3. 具有抽象逻辑思维
4. 具有可逆性、补偿性和灵活性
