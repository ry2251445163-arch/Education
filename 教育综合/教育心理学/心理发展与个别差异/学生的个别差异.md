# 一、能力差异
## 个体差异
1. 发展水平差异——能力有高低差异，有人水平高，有人水平低
2. 类型的差异（能力结构的差异）——构成能力因素存在差异，知觉、记忆、注意等存在差异
3. 表现早晚差异——大器晚成
## 群体差异
不同群体之间的智力差异
例如，性别差异：
1. 男女智力的总体水平大致相等
2. 男女智力结构存在差异

### （2）柯勃的划分

|    类型    | 优点                 |          缺点          |
| :------: | :----------------- | :------------------: |
|   顺应型    | 喜欢执行计划，付诸行动        | 改进任务，不能及时完成任务，容易偏离目标 |
|   同化型    | 能理解大量信息，整理归类，制定计划  |         缺乏实践         |
| 集中型（聚合型） | 寻求实际应用，善于解决问题和做出决定 |         仓促决定         |
|   发散型    | 能不同角度看问题           |         难以抉择         |
