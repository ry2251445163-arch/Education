# 3.3社会规范的背离
## 概念
对社会规范、准则的偏离、违反、背叛等
## 社会背离的类型
### （1）按危害程度
1. 社会适应障碍——心理障碍或心理疾患所引起的
2. 品德不良
3. 违法犯罪
### （2）按背离根源
1. 错误依从——迫于群体的内部压力
2. 错误认同——由于情感、个性
3. 错误信奉——由于生活环境与特殊经历
## （3）按综合要素
1. 过失型
2. 品德不良型
3. 攻击型
4. 压抑型
