# 趋势
1. 从简单、具体不断向复杂、概括发展
2. 从无意向有意发展
3. 从笼统向分化发展
4. 从零散到形成系统
# 基本特征（规律）
1. 阶段性与连续性
2. 定向性与顺序性
3. 不平衡性
4. 差异性
# 一般特征
## 小学生
1. 迅速性
2. 协调性
3. 开放性
4. 可塑性
## 中学生
1. 过渡性
2. 闭锁性
3. 社会性
4. 动荡性
# 阶段特征
## 童年期
生长发育最旺盛、变化最快、可塑性最强、接受教育最佳的时期
## 少年期
也称“心理断乳期”或“危险期”
1. 抽象思维占主导
## 青年期
1. 抽象思维从“经验型”向“理论型”转化
