# 概念
广义：人类的学习和动物的学习
狭义：人类的学习
1. 学习不仅指学习后所表现的结果，也指行为变化的过程
2. 学习的行为变化是由经验引起的
3. “行为”既包括可观察的外显行为，也包括不能直接观察的内潜行为
4. 学习的行为变化是比较持久的
# 分类
## 一、[[加涅关于学习的分类]]
### （1）按学习水平分类
1. 信号学习——过程：刺激-强化-反应
2. 刺激-反应学习
3. 连锁学习——学习联合两个或两个以上的刺激-反应动作
4. 语言联结学习
5. 辨别学习
6. 概念学习——认识一类事物的共同属性
7. 规则或原理学习——学习两个或两个以上概念之间的关系
8. 解决问题学习
### （2）按学习结果分类
1. 语言信息的学习——解决“是什么”
2. 智慧技能（智力技能、心智技能）的学习——解决“怎么做”
3. 认知策略的学习——“管理”自己学习过程
4. 动作技能（运动技能）的学习
5. 态度的学习
#### 2.1 态度的学习
1. 儿童对家庭和其他社会关系的情感体验
2. 对某种活动表现出来的积极的、喜爱的情感
3. 有关个人品德的某些方面，如热爱国家
