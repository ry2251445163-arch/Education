1. 正强化与负强化
[[正强化]]：反应后给予愉快刺激
[[负强化]]：反应后摆脱厌恶刺激——逃避条件作用和回避条件作用
2. 一级强化和二级强化
一级强化：生理需要
二级强化：社会强化，信物和活动
3. [[普雷马克原理]]（又称祖母原则）
首先做我要和你做的时期，然后才可以做你想做的事情
4. 强化程式（强化程序）
前连续强化，中定时强化，后变时强化

| 程序分类  | 定义          | 示例      |
| ----- | ----------- | ------- |
| 连续强化  | 给予每个反应强化    | 一按开关灯就亮 |
| 定时强化  | 固定时段给予强化    | 按时发工资   |
| 变时强化  | 不定时给予强化     | 不定时随堂检测 |
| 定比率强化 | 固定反应次数后给予强化 | 计件工作    |
| 变比率强化 | 不定反应次数后给予强化 | 老虎机；买彩票 |
呈现不同变化趋势的现象——[[德西效应]]
