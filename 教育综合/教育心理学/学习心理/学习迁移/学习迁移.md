# 一、[[学习迁移的概念和作用]]
## （1）学习迁移的概念
1. 也叫训练迁移
2. 一种学习对另一种学习的影响，如“举一反三”“触类旁通”
3. 只要有学习，就有迁移
## （2）学习迁移的作用
1. 有助于知识的获得和应用
2. 有助于能力的形成
3. 有助于知识、经验的概括化和系统化
4. 有指导作用
# 二、[[学习迁移的类型]]
## （1）顺向迁移和逆向迁移（按照迁移的时间顺序划分）
1. 正迁移——助长性迁移、积极迁移
2. 负迁移——抑制性迁移、消极迁移

## （2）正迁移、负迁移和零迁移（按照迁移的性质划分）
## （3）水平迁移和垂直迁移（按照迁移内容的不同抽象和概括水平划分）
## （4）一般迁移和具体迁移（按照前已的发生方式和范围划分）
## （5）同化性迁移、顺应性迁移和重组性迁移（按照所需的内在心理机制划分）
## （6）自迁移、近迁移和远迁移（按照迁移前后情境划分）
## （7）低路迁移和高路迁移（按照迁移的路径或迁移发生的自动化水平划分）
# 三、[[学习迁移理论]]
## （1）早期学习迁移理论
### 1. 形式训练说
1. 沃特夫
2. 通过训练可以使~={red}心智的官能（记忆、思维、听力、视力）=~得到发展，从而迁移到其他学习上去
3. 大量训练
4. 学习的内容不重要
### 2. 相同要素说
1. ~={red}桑代克=~、伍德沃斯
2. “形状知觉”实验
3. 只有当两个机能因素中有相同的要素，一个机能的变化才会改变另一个机能的习得。
### 3. 概括化理论（经验类化说）
1. ~={red}贾德=~
2. ~={red}“水下击靶”=~
3. 迁移产生的关键——两种活动中通过~={red}概括=~形成了能够泛化的共同原理
4. 只要一个人对他的经验~={red}进行了概括，就可以完成迁移=~
### 4. 关系转换说（关系理论）
1. 苛勒——~={red}格式塔=~心理学
2. “小鸡啄米（小鸡觅食）”
3. 察觉到手段和目的之间的关系，是实现迁移的根本
