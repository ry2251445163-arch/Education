[[维纳]]
### 1. 基本观点

| 因素   | 内部  | 外部  | 稳定  | 不稳定 | 可控制 | 不可控制 |
| ---- | --- | --- | --- | --- | --- | ---- |
| 能力高低 | ✔   |     | ✔   |     |     | ✔    |
| 努力程度 | ✔   |     |     | ✔   | ✔   |      |
| 任务难易 |     | ✔   | ✔   |     |     | ✔    |
| 运气好坏 |     | ✔   |     | ✔   |     | ✔    |
| 身心状态 | ✔   |     |     | ✔   |     | ✔    |
| 外界环境 |     | ✔   |     | ✔   |     | ✔    |
### 2. 教育启示
1. 将失败归因于缺少能力或努力，则产生羞愧和内疚
2. 将失败归因于任务太难或运气不好，产生羞愧较少
### 3. [[习得性无助感]]
1. 由于连续的失败体验而导致个体产生对行为结果感到无力控制、无能为力的额心理状态
2. 主要是把失败归因于内部的、稳定的和不可控制的因素（即能力低）的学生
